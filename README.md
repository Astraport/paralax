# Атлас тихих мест

Браузерное приложение с пятью параллакс-сценами:

1. Пруд на закате: берег, небольшая лодка в глубине, причал с удочкой и камыш. Лодка слегка покачивается отдельно от движения причала.
2. Греческая деревня: море и горы, отдельный слой дальних домов на береговом выступе, синяя ограда, олива и апельсиновое дерево.
3. Комната СССР: ковёр на стене, сервант, кресло, стол с вазой, два отдельных стула и мячик.
4. Лунный портал: долина с огромной луной, дальний лес, светящийся каменный проход, два дерева у камеры и папоротники. Этот пример открывается первым.
5. Мезозойская долина: вулкан, река, зауроподы, парящие птерозавры, тираннозавр и два плана папоротников.

В сценах от четырёх до семи независимых планов. Под сценой перечислены планы; нажатием на название можно скрыть или вернуть любой из них. У пруда один и тот же вырез камыша размещён в двух точках переднего плана.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Можно также запустить локальный сервер:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Параметр адреса `?scene=portal`, `?scene=pond`, `?scene=greece`, `?scene=room` или `?scene=meso` открывает нужный пример сразу. Кнопка в правом верхнем углу сцены разворачивает её на весь экран.

## Управление

- **Авто:** планы движутся из стороны в сторону с разной амплитудой. Лодка покачивается, птерозавры парят по собственным траекториям. Мышь не влияет на сцену.
- **Мышь:** автоматическое движение выключено; движение курсора, перетаскивание или стрелки клавиатуры двигают планы.
- **Пауза:** планы остаются на месте. Мышь не влияет на сцену.

Режим сохраняется при переключении между локациями. При `prefers-reduced-motion` приложение стартует на паузе, а автоматический режим отключён.

Изображения созданы встроенным imagegen и сохранены в `assets/` в WebP. Промпты записаны в `ASSET_PROMPTS.md`. Для реализации были рассмотрены [Parallax.js](https://github.com/wagerfield/parallax) и [Atropos](https://atroposjs.com/); собственный контроллер на `requestAnimationFrame` управляет несколькими сценами и тремя взаимоисключающими режимами без внешней JS-библиотеки.
